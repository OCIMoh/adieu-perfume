# scroll-world

An agent skill for engineering immersive, scroll-scrubbed "fly through the world" camera journeys for physical products, craft, and architectural brands.

## Structure

```text
scroll-world/
├── LICENSE
├── README.md
├── SKILL.md                          # Main agent skill definition & procedural contract
└── canvas-starter/                   # Minimal 4-file Apple-grade Canvas Frame Engine
    ├── package.json
    ├── index.html
    ├── engine.ts                     # Canvas 2D + Two-tier preloader + Lenis & ScrollTrigger
    └── style.css                     # Editorial typography & responsive layout
```

## Quick Start for Frontend

```bash
cd canvas-starter
npm install
npm run dev
```
